# 模型卡 — c2sim 仿真保真度与有效边界

> 一套仿真的可信度 = **清楚知道它在哪里成立、在哪里不成立**。本卡声明
> `c2sim` 的建模假设、保真度等级与已知局限,供使用其结论者据此判断适用性。
> 本项目为**纯软件仿真**,不接入真实装备、不读取真实世界数据。

## 用途与非用途

- **适用**:指控算法验证(融合/研判/分配/制导对比)、部署方案与效费比的
  相对比较、训练与兵棋推演、链路逻辑回归。
- **不适用**:绝对性能预测、装备选型背书、对真实交战结果的定量外推。
  结论应作**相对比较**(A 方案 vs B 方案),而非绝对数值承诺。

## 坐标系与积分

| 项 | 建模 | 局限 |
| --- | --- | --- |
| 空间 | 直角坐标点质量,单位米 | 无地理投影、无地球曲率 |
| 时间 | 固定步长显式积分(默认 0.5s) | 大步长有离散误差;近炸已用步内最近接近(CPA)缓解 |
| 运动 | 匀速/寻的;目标末段加速 | 无六自由度、无气动 |

## 各环节保真度

### 传感器(Spotter Pro)
- **频谱测向**:建模为**引导线索**(为雷达提供方位、标记 RF 辐射源),
  **不产生三维位置量测**(真实为二维测向、无距离)。
- **雷达**:三维量测,作用距离按 RCS 幂律标定(0.01㎡→5km、0.2㎡→10km);
  **俯仰角误差 > 方位角误差**(高度误差更大);TAS 容量、近界盲区、扇区
  覆盖均建模。
- **光电**:高精度角度(0.15mrad)+ 识别,单转台、就近优先。
- **杂波/虚警**:可配置(`clutter_rate`,默认 0)。**M-of-N 航迹确认**
  (`confirm_threshold`,默认 1)抑制杂波激起的暂定航迹——仅已确认航迹进入
  研判/交战。实测重杂波下确认航迹峰值由 ~60(无确认)降至 ~5(N=5,逼近 4
  个真实目标),Thunder 浪费与突防同步下降。

### 航迹融合
- 默认:多源量测**逆方差(标量 σ)加权** + 最近邻波门关联 + α-β 滤波。
- **可选(已提供)**:`tracking.CovarianceTracker` —— 量测携带各轴方差
  (LOS 角误差投影,见 `geometry.los_diag_var`),做**逐轴卡尔曼**融合,真正
  利用各向异性:雷达俯仰(高度)噪声大则少更新 z,光电精度高则强收紧。
  实测(纯雷达、远距)平均高度误差较标量 α-β 降约 **23%**(160→123m)。
  经 `Engine(..., tracker=CovarianceTracker())` 注入(P1 `Tracker` 接缝的实证)。
- ⚠️ 残留:仍为**对角**协方差(忽略轴间相关),关联用欧氏波门而非马氏距离;
  无 JPDA/MHT/IMM。
- ⚠️ 数据关联为几何最近邻,无 JPDA/MHT;密集/交叉目标可能误关联。

### 威胁研判
- 四因子(企图/紧迫/逼近/杀伤)加权;目标类型优先取**光电识别**,否则
  运动学粗分类。权重为工程设定,非经验标定。

### 拦截(Thunder)
- 三阶段制导;末段以弹载导引头锁定**真实目标**(注入导引头噪声)寻的。
- **转弯率约束**已建模(`max_turn_rate`,默认 2.0 rad/s ≈ 8g@67m/s):
  实际速度每步至多朝制导指令旋转 `max_turn_rate·dt`。
- 毁伤:步内最近接近 ≤ 杀伤半径触发引信,毁伤概率由**脱靶量经战斗部毁伤
  函数**(高斯型,`world.kill_probability`)给出,上限为 `warhead_reliability`
  (默认 0.95,引信/战斗部可靠性);**实现单发 Pk 由脱靶分布涌现**(实测约
  78–83%),非硬设。
- ⚠️ **真值兜底**:末段以最近真实目标/所锁真值寻的,**绕过了误关联**这一
  真实难题——故对**密集诱饵/僚机**场景会高估末段命中。

### 软杀伤(Hunter Max)
- 对**依赖 RF 链路**目标在干扰圈内致链路中断 → 持续达阈值判迫降/返航;
  **RF 静默自主目标免疫**。
- ⚠️ 简化:未区分通信链路干扰 vs GPS 压制/诱骗;无抗扰成功概率、无干扰
  功率/距离衰减、无多目标分摊。

## 会系统性影响结论的简化(务必知悉)

1. **无遮挡/地形/多径**:视距无阻断,低空贴地目标不受地形掩护。
2. **无通信时延**:指控-发射-Thunder 链路零时延;真实有响应链路耗时。
3. **无去冲突/反误伤**:未建模 Thunder 互撞、穿越干扰区、友邻误伤。
4. **传感器真值索引**:传感器/导引头按真值目标建模波束指向,误关联被弱化。
5. **融合标量 σ**:见上,高度精度收益被低估或近似。

以上 1–4 多倾向**高估防御效能**;使用绝对数值时应保守看待。

## 复盘补充:方法论偏置与设计取舍(务必知悉)

以下问题经批判性复盘识别,**不通过调参"修掉"**,而是据实声明,供解读结论时校正:

1. **默认想定经人工调参偏向"零突防"**:点状/带状想定的发射平台位置、数量、
   RCS、`engage_radius_frac` 等被调到接近零突防,属**对满意结果的过拟合**。
   故**单一默认想定的胜负不可作为效能证据**;请用 `--monte-carlo` 看分布,
   或用 `swarm`(未刻意调赢、会饱和突防)做压力对照。
2. **Pk 循环论证(已拆除)**:此前 `single_shot_pk≈0.92` 为匹配规格而设、再"验证"
   规格,属假设即结论。现改为**由脱靶量经战斗部毁伤函数涌现**(输入仅
   `warhead_reliability`=脱靶 0 时上限),实测实现 Pk ~78–83%——**诚实地低于
   规格 ≥90%**,未上调以迁就规格(那正是要拆除的循环)。残留:毁伤函数形状
   (高斯)与可靠性取值仍是建模选择。
3. **末段锁定与火力分配——已硬绑定 + 误关联建模**(原"脱钩"问题已修):
   末段锁定以**指控上行的所分配航迹**为线索,在导引头视场内锁定最接近线索的
   真实目标;锁定与 `engaged_counts` 现都以分配航迹为准,语义自洽。**误关联**
   作为几何涌现:邻近目标更接近线索时被锁错(见 `select_seeker_lock` 与
   `tests/test_association.py`)。蒙特卡洛对比:点状无变化(稀疏,线索最近==
   全局最近),蜂群效费比 9.43→9.35(微改善),处置/突防基本持平——说明在
   现实 C-UAS 间距下脱钩的数值影响很小,本项价值在**正确性**而非刷分。
   **末段细化(已建模)**:视场内锁定改为**信杂比加权概率锁定**(权重
   ∝ RCS/(1+(距线索/门限)²)),强回波邻近诱饵可夺锁;支持**丢锁/再捕获**
   (所锁目标被他弹击杀或 `lock_loss_prob` 触发即重搜,回收废弹)。
   蒙特卡洛:再捕获使蜂群效费比 9.35→8.95;`decoy` 想定中亚视场强回波诱饵
   使真目标突防率由 ~5%(无诱饵)升至 ~47%(+~42pp),量化了误关联战术效果。
   ⚠️ 残留简化:未建模视场内**遮蔽、再捕获时延、诱饵抛射动力学**;
   `lock_loss_prob` 默认 0(作为研究开关,非标定值)。
4. **覆盖面积**(已修):多站覆盖经蒙特卡洛估算**真实并集**
   (`union_coverage_km2`),不再直接相加重复计入重叠(例:蜂群 3 站由直加
   235.6 km² 修正为并集 156.1 km²)。
5. **无独立验证基准(oracle)**:除几何(领先拦截/CPA)有解析单测外,系统级
   结论无真值校验。一切数值应作**相对比较**(A 方案 vs B 方案)。这是当前
   **最大的剩余短板**——下一步价值在接入真值/高保真轨迹交叉验证,而非叠算法。

> **敏感性说明**:`--sensitivity N`(`sensitivity.py`)逐参数扫描输出对突防率的
> 摆幅,使上述结论附带"对哪些输入敏感"的量化依据(例:蜂群中 jam 覆盖、探测
> 距离主导,Thunder 机动/可靠性影响较小)。

## 默认关键参数(可在想定中覆盖)

| 参数 | 默认 | 出处 |
| --- | --- | --- |
| 安全穹顶半径 | 5 km | 规格 |
| Thunder 最大速度 | 66.7 m/s(240 km/h) | 规格 |
| Thunder 作业半径 | 5 km | 规格 |
| Thunder 最大转弯率 | 2.0 rad/s | 工程设定(敏捷弹) |
| 战斗部可靠性 | 0.95 | 脱靶=0 时毁伤上限;实现 Pk 由脱靶分布涌现(~78–83%) |
| 雷达精度 | 距≤10m、角≤0.5°(俯仰更差) | 规格 |
| 仿真步长 | 0.5 s | 工程设定 |

参数与算法均可替换:策略经 `strategies.py` 协议注入,想定经 `scenario_io`
以 JSON 声明,效能经 `metrics` 蒙特卡洛统计。
