# 用户故事与验收(可测试)

需求拆解为**可测试用户故事**,每条带验收准则并**追溯到自动化测试**——构成
故事↔测试的可核查矩阵。运行 `python -m unittest discover -s tests` 验证。

格式:作为 <角色>,我要 <能力>,以便 <价值>。**验收** → 覆盖测试。

---

### 探测 / 跟踪 / 研判

- **US-01 多源航迹融合**:作为分析员,我要把多部传感器的带噪量测融合成单条
  稳定航迹,以便获得可用态势。
  **验收**:同目标的多源邻近报告融合为一条航迹;光电高精度量测主导融合位置;
  航迹起批/惯性外推/撤销正常。→ `tests/test_fusion.py`
- **US-02 多模态探测**:作为分析员,我要频谱测向引导雷达、雷达引导光电,并体现
  TAS 容量/盲区/扇区限制。**验收**:RF 静默目标仍被雷达跟踪;TAS 容量上限生效;
  光电产出识别;盲区/扇区外不探测。→ `tests/test_sensors.py`
- **US-03 协方差跟踪(可注入)**:作为研究者,我要用各向异性误差感知的跟踪器
  改善高度估计。**验收**:纯雷达远距下高度误差较标量 α-β 降 ≥10%。
  → `tests/test_tracking.py`
- **US-04 杂波鲁棒(M-of-N 确认)**:作为分析员,我要杂波激起的暂定航迹不污染
  指控画面。**验收**:重杂波下确认航迹峰值远低于无确认;无杂波不误伤真实航迹。
  → `tests/test_confirmation.py`
- **US-05 威胁研判排序**:作为分析员,我要按威胁对航迹排序。**验收**:来袭比掠过
  威胁高;直扑目标有抵达时间;低置信航迹被折扣。→ `tests/test_threat.py`

### 拦截 / 杀伤

- **US-06 火力-目标分配**:作为分析员,我要据威胁与平台资源分配 Thunder。
  **验收**:达阈值即交战并扣库存;超作业半径下发 HOLD;择库存多者。
  → `tests/test_interception.py`
- **US-07 软/硬结合杀伤**:作为分析员,我要 RF 制式目标优先软杀伤、RF 静默由
  Thunder 硬杀伤。**验收**:RF 目标被干扰迫降且不耗 Thunder;RF 静默目标免疫
  干扰。→ `tests/test_jamming.py`
- **US-08 末段寻的与误关联**:作为研究者,我要末段以分配航迹为线索、信杂比加权
  锁定,并能表现诱饵误关联。**验收**:线索牵引锁定;强回波诱饵按概率夺锁;
  亚视场诱饵显著抬高真目标突防。→ `tests/test_terminal.py`, `tests/test_association.py`
- **US-09 涌现毁伤概率**:作为研究者,我要单发 Pk 由脱靶量经毁伤函数涌现,而非
  硬设。**验收**:可靠性↑→突防↓(单调);全程零硬杀伤时效费比为未定义而非 0。
  → `tests/test_metrics.py`, `tests/test_sensitivity.py`

### 引擎 / 物理

- **US-10 端到端交战**:作为分析员,我要跑完一个想定并得到结局账目。**验收**:
  全部目标恰好落入 摧毁/软杀伤/突防/在途 之一;库存非负;真值隔离(航迹无真值
  身份)。→ `tests/test_engine.py`
- **US-11 保真度约束**:作为研究者,我要 Thunder 受转弯率约束、可注入虚警/杂波。
  **验收**:转弯率越小拦截代价不降;杂波下仍处置真实目标。→ `tests/test_fidelity.py`
- **US-12 几何/运动学**:作为开发者,我要可靠的 CPA、领先拦截解算与各向异性噪声。
  **验收**:解析算例匹配;不可达返回 None。→ `tests/test_geometry.py`

### 平台能力

- **US-13 蒙特卡洛 MOE**:作为分析员,我要跨种子统计效能(均值/标准差/95%CI/
  零突防率/效费比)。**验收**:聚合统计正确;CI 用样本标准差。→ `tests/test_metrics.py`
- **US-14 参数敏感性**:作为分析员,我要知道结论对哪些参数敏感。**验收**:逐参数
  扫描按摆幅降序;可靠性单调。→ `tests/test_sensitivity.py`
- **US-15 想定即数据**:作为分析员,我要用 JSON 编写/版本化想定且有清晰校验。
  **验收**:回环保真(含 terminal_range);缺字段/非法枚举/未知字段/负值报清晰
  错误。→ `tests/test_scenario_io.py`
- **US-16 算法可替换(DI)**:作为研究者,我要不改引擎即可换跟踪/研判/分配/制导。
  **验收**:协议符合;注入替代实现可运行;制导律满足契约。→ `tests/test_strategies.py`
- **US-17 态势可视化**:作为导调,我要俯视态势图。**验收**:生成含穹顶/覆盖/航迹/
  事件标记的合法 SVG。→ `tests/test_viz.py`
- **US-18 规模/蜂群**:作为分析员,我要支持数十目标蜂群并演示饱和。**验收**:蜂群
  全目标账目守恒、处置过半;空间索引与暴力遍历精确一致。
  → `tests/test_scale.py`, `tests/test_spatial.py`

### 验证(独立 oracle 框架)

- **US-20 外部真值交叉验证**:作为研究者,我要用外部真值轨迹独立检验传感+跟踪
  精度,以便获得不依赖自身假设的验证。**验收**:`TruthTrack` 数据契约 + CSV 接入;
  `Validator` 输出 RMSE/各轴/关联率;对任意 `Tracker` 实现可用;管线自检可复现。
  ⚠️ 合成轨迹仅自检、非 oracle;真实数据待接入。→ `tests/test_validation.py`

### 工程不变量(回归守护)

- **US-19 复现性/无全局态**:作为开发者,我要 ID 按次复现、不靠全局可变状态。
  **验收**:同种子两次运行指令/航迹 ID 一致。→ `tests/test_retrospective_fixes.py`
