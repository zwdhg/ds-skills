# PRD —— 演练指挥控制系统(反无人机 C-UAS 仿真)

> 本文档是**回填式 PRD**:系统已实现,此处固化其意图、范围与验收口径,作为
> 后续迭代的"北极星"。需求→可测试用户故事见 [`user-stories.md`](user-stories.md);
> 保真度边界见 [`model-card.md`](model-card.md)。

## 1. 愿景

一套**离线、自洽、零第三方依赖**的反无人机(C-UAS)对抗仿真**分析平台**,
用于训练、兵棋推演与**指控算法验证**。复现"侦测→融合→研判→拦截指令→
软/硬杀伤"全链路,并支持算法可替换、统计评估与诚实的边界声明。

## 2. 范围与非目标(硬约束)

- ✅ **纯软件仿真**:目标/传感器/武器均为数学模型,在模拟环境内运行。
- ❌ **非火控系统**:不接入真实装备、不读取真实世界目标数据、不产生现实动作。
- ❌ 不追求绝对性能预测;结论仅用于**相对比较**(方案/算法 A vs B)。
- 参考系统为**防御性 C-UAS**(见 `reference-system.md`),非进攻性武器。

## 3. 用户与场景

| 角色 | 目标 |
| --- | --- |
| 分析员 | 比较部署方案/算法的效能(MOE),做参数敏感性分析 |
| 教练/导调 | 用想定做训练与兵棋推演,复盘交战过程 |
| 研究者 | 在固定环境下验证跟踪/研判/分配/制导算法 |

## 4. 功能需求

1. **多模态探测**(Spotter Pro):频谱测向→AESA 雷达→光电级联引导。
2. **航迹融合**:多源带噪量测→稳定航迹(可替换:标量 α-β / 协方差卡尔曼)。
3. **威胁研判**:四因子加权,优先光电识别类型。
4. **拦截指令生成**:火力-目标分配(作业半径/库存约束)。
5. **软/硬杀伤**:Hunter Max 干扰(RF 制式)+ Thunder 动能拦截(三阶段制导)。
6. **想定即数据**:JSON 声明 + 校验;四类部署(点状/带状/蜂群/诱饵)。
7. **统计评估**:蒙特卡洛 + MOE(突防率/处置率/效费比 + 95%CI)。
8. **敏感性分析**:逐参数扫描对 MOE 的影响。
9. **可视化**:无依赖 SVG 态势图。
10. **可扩展**:算法经协议依赖注入,新增实现零改引擎。

## 5. 非功能需求(质量门)

- **零第三方依赖**(仅标准库);`python -m unittest` 可全过。
- **确定性**:结构性重构须保持逐种子逐字节不变(随机数调用顺序不变)。
- **诚实度量**:行为变更必须用蒙特卡洛前后对照佐证;**严禁**为匹配目标值
  反向调参(如 Pk 循环标定);新增局限须写入 `model-card.md`。
- **真值隔离**:指控链路只见带噪航迹,真值物理封装在 `world.World`。

## 6. 验收口径(成功标准)

- 全部用户故事的验收准则均有对应自动化测试(见 `user-stories.md` 追溯表)。
- MOE 以分布 + 置信区间呈现,而非单次点估计。
- 关键保真度量(实现 Pk、覆盖并集、跟踪精度)为**涌现/实测**,非硬设。

## 7. 已知局限(诚实声明,见 model-card)

**最大剩余短板:无独立验证基准(oracle)**——一切数值仅在模型假设内自洽。
这需要外部真值/高保真轨迹交叉验证,非仓内能自证;故标为下一步价值所在。
