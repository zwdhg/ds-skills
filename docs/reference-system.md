# 参考系统规格摘要 — 塞防科技 智能反无人机防御体系

> 本文件是对参考资料(产品方案 PDF)的**规格摘录**,用于指导 `c2sim` 仿真
> 的参数与架构对齐。本项目是**纯软件仿真**,不接入任何真实装备。参考系统
> 本身是一套**防御性反无人机(C-UAS)系统**,而非火控系统。

## 体系构成

| 单元 | 角色 |
| --- | --- |
| **Spotter Pro** | 地面多模态探测:频谱测向 + X 波段 AESA 雷达 + 光电,"侦测—识别—跟踪" |
| **Skyshield Nexus** | 指控中枢:航迹融合、威胁等级研判、拦截策略与指令生成、自主调度 Thunder |
| **Thunder** | AI 自主截击机:起飞抵近 → 目标搜索 → 末段拦截 |
| **发射平台** | Thunder 的填装、防护、部署与远程发射 |
| **Hunter Max** | 固定式无线电干扰设备(软杀伤,已建模) |

## 工作流(三环节)

1. **目标探测**:频谱测向二维定向(≥10km 预警)引导雷达波束扫描 → 检测与
   稳定跟踪 → 自主调度光电完成识别与精确锁定;多源异构融合改善传统雷达
   **俯仰测量误差大**、制约初-中制导交班的问题。
2. **态势研判,智能决策**(Skyshield Nexus):多源探测信息 → 航迹融合 →
   威胁等级研判 → 拦截策略生成 → 结合 Thunder 分布式部署/待机位置/可用资源
   优选最优拦截单元 → 下发精确制导与拦截控制指令。
3. **自主拦截**(Thunder):起飞抵近 → 目标搜索 → 末段拦截。

## 关键规格

### Spotter Pro — 频谱测向模块
- 侦测频段:频谱 0.4–6 GHz;协议 2.4 / 5.8 GHz
- 测向体制:二维多基线相位干涉仪
- 测向精度:≤5.0° rms@0.4GHz … ≤1.5° rms@5.8GHz
- 覆盖:水平 360°,俯仰 −30°~75°
- 侦测距离:**≥10 km**

### Spotter Pro — 雷达模块(AESA)
- 工作频段:X 波段(9.2–9.8 GHz)
- 侦测距离:RCS 0.01㎡ ≥5km;RCS 0.2㎡ ≥10km
- 覆盖:水平 360°,俯仰 0°~30°(最大可扩展 60°)
- 目标容量:搜索 TWS ≥500;**跟踪 TAS ≥6**
- 精度:距离 ≤10m、速度 ≤1m/s、方位 ≤0.5°、俯仰 ≤0.5°
- 盲区:≤200 m

### Spotter Pro — 光电模块
- 可见光:探测 ≥12km / 识别 ≥10km(3.5×2.5m UAV)
- 红外:探测 ≥8km / 识别 ≥5km
- 伺服转台:水平 ≤120°/s,俯仰 ≤90°/s;**跟踪精度 ≤0.15 mrad**

### Thunder(拦截机)
- 单台拦截成功率:**≥90%**(典型目标 Shahed-136)
- 作业半径:**5 km**;实用升限:3 km
- 最大平飞速度:**≥240 km/h(≈66.7 m/s)**;巡航 150 km/h(≈41.7 m/s)
- 控制模式:全任务流程自主控制,支持手动接管;任务载荷 0.4 kg

### 发射平台
- 支持单台 Thunder 填装部署;支持远程控制开启

### Skyshield Nexus
- 可连接子设备 ≤50 台;典型续航 3h;IP65

## 典型部署

- **边境线带状防护**:多台 Spotter Pro 沿线分布,180° 扇区朝境外;
  单组(180°,半径 5km)覆盖 ≈ **39.27 km²**。
- **核心要域点状防护**:中心/制高点单套 Spotter Pro 360°;Thunder 分布式
  前置部署;形成半径 5km "安全穹顶",防护面积 ≈ **78.5 km²**。

## 仿真对齐取舍

- 频谱测向在真实系统中是**二维定向(无距离)**,主要用于**远程预警与引导
  雷达**。仿真中据此建模为:为雷达提供**早期截获线索(cue)**,而非直接产生
  三维位置量测。
- "传统雷达俯仰误差大"在仿真中建模为:雷达**俯仰角误差大于方位角误差**
  (即高度误差大于水平误差),再由**光电的高精度角度量测**经多源融合收紧
  高度精度——以此体现多模态融合的工程价值。
- Thunder 为**动能拦截**(撞击);单发毁伤概率不再硬设,而由脱靶量经战斗部
  毁伤函数(`world.kill_probability`,上限 `warhead_reliability`)涌现,实测约
  78–83%(诚实低于规格 ≥90%,未上调迁就规格)。
- Hunter Max 软杀伤建模为:对**依赖 RF 链路**(辐射射频信号)的目标在干扰
  半径内致链路中断(悬停/失速),持续达阈值判**迫降/返航**;**RF 静默的
  自主目标(GPS 制导巡飞弹)免疫**——故须由 Thunder 硬杀伤。Skyshield Nexus
  对 RF 制式目标优先软杀伤以节省 Thunder。
